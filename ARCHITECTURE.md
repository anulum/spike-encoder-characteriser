# Architecture

## Current executable surface

The checkout contains repository validation tools, dedicated tests, workflow definitions and native documentation. No domain package, encoder runner, trained decoder, probe result or qualified characterisation is available. Repository metadata keeps domain capabilities and claims empty.

## Intended data flow

A frozen protocol binds complete continuous records, original sample/channel maps, source versions, seven software families, parameter points and trials. Explicit adapters invoke the actual imported encoder and preserve complete raster and spike-log output. Training-only decoder/probe fitting consumes fixed disjoint inventories. Metrics retain unavailable quantities, missing records and censoring before the complete cloud and comparable front are assembled.

## Ownership

SC-NeuroCore owns the encoding algorithms. This project owns admission, adapters, measurement, comparison and reporting. Evidence Manifest Toolkit owns common evidence assembly and verification; Spike Log owns the typed output container. Studio, Neuro Evidence Bench and deployment selection consume admitted values rather than duplicate metrics.

## Validity and recovery

One native result contains one stimulus/family/lane/protocol and its complete selected grid. Missing or incomplete original-record output cannot become a zero-spike observation. Normalised reconstruction can be negative; zero oracle loss leaves the score unavailable. Model windows and physical capture use distinct methods. Recovery preserves prior failed attempts and unchanged plan/source identity.

Further public tooling details are in [the documentation architecture](docs/ARCHITECTURE.md).
